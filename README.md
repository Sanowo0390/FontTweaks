# FontTweaks

Minecraft 26.3 / Fabric / クライアント専用

Unifontのドット加工、内蔵フォントへの置換、文字倍率・字間・行間を調整します。設定画面はMod Menuから開けます。Fabric APIとYACL v3が必要です。

## プリセット

| プリセット | GUI1 | GUI2 | GUI3 | GUI4以上 |
| --- | --- | --- | --- | --- |
| 1. ドット補正のみ | 標準・加工1px | 標準・無加工 | 標準・加工1px | 標準・無加工 |
| 2. 補正＋フォント変更 | 美咲・3px設定 | 標準・無加工 | PixelMplus12・2px設定 | 標準・無加工 |
| 3. 常に美咲 | 美咲・3px設定 | 美咲・3px設定 | 美咲・3px設定 | 美咲・3px設定 |

全プリセットで英字置換はOFFです。プリセットの変更は画面内へ即時反映され、保存するまで適用されません。個別編集すると「カスタム」になります。

## 設定画面

- **フォント・ドット**：プリセットとGUI1・2・3・4以上のプロファイル。ドットの粗さ、内蔵フォント、標準フォントのドット補正、英数字の字体変更をGUI別に設定できます。
- **文字**：全体・画面・HUD・ボタン・チャットの倍率、横の文字間隔、全体・文章・ツールチップの行間、英字の間隔調整除外。
- **除外文字**：フォント置換から除外する文字を追加・編集・削除できます。

既存フォントONの場合、3pxは美咲、それ以外はPixelMplus12です。旧設定から移行した明示フォント指定は個別編集まで保持します。ドット加工は標準Unifontが対象で、内蔵フォントの画像自体を加工しません。

「ドットの粗さ」は標準フォントの加工の細かさです。1は細かく、4に近づくほど粗くなります。数値はGUIサイズ3基準の設定で、すべてのGUIサイズで同じ画面上のドット幅になるわけではありません。文字全体の大きさは「文字サイズ・間隔」で調整します。GUI2とGUI4で1pxの場合は元のUnifontを使用します。GUI4以上の設定は共通ですが、この無加工特例はGUI4にだけ適用されます。GUI別の加工OFFでは文字位置のピクセル補正も行いません。

FontTweaks自身の設定画面の操作文字は倍率・字間・行間の調整対象外です。右側のサンプルは**現在適用済みの設定**を示します。未保存の変更を反映するライブプレビューではありません。

## 互換性と再読み込み

ドットの粗さは **1〜4だけ**選べます。旧設定で「自動」として記録された数値 `0` は、同じ加工になる `2` に自動移行します（新規設定の初期値は1）。

設定ファイルは `config/fonttweaks.json` です。旧フォント指定・旧ブラックリスト・旧GUI5以上プロファイルの移行を維持しています。GUI4がある場合はGUI4を優先し、GUI5以上しかない場合はGUI4以上へ引き継ぎます。

GUIサイズの変更、プリセットの適用、ドット補正・字体・英数字の変更、文字サイズ・間隔・除外文字の保存では、リソースを再読み込みしません。標準画像と粗さ1〜4の加工画像を、表示した文字に限って必要時に生成し、切り替えて使います。同じ加工の画像は再利用します。1文字につき最大5種類の画像を保持するため、複数の加工を使った場合は文字画像のメモリ使用量が増えます。リソースパック変更やF3+TによるMinecraft本来の再読み込み時には、古い文字画像も破棄されます。

## ビルドと検証

Java 25 / Gradle 9.7.1を使用します。

```sh
gradle clean build
gradle runSmoke -x downloadAssets
python3 scripts/verify_font_assets.py
```

GitHub Actionsの成功した実行のArtifactsからJARをダウンロードできます。ビルド時に固定バージョンのフォントを取得してSHA-256を検証します。JUnitとMixinスモークテストは実機での見た目や他Modとの全組み合わせを保証するものではありません。
