# FontTweaks 0.4.3

Minecraft 26.3 / Fabric / client-only

## 0.4.3の変更

設定を1〜4画面pxへ拡張し、日本語UIの名称を「ピクセル加工」へ統一しました。ツールチップから「半透明ドットは使いません。」を削除しました。1画面pxの画像加工方式は0.4.2から変更していません。

GUI4・4画面pxでは標準英字とドット幅が一致するため美咲を選択します（Unicodeフォント強制OFF）。自動GUIでも実効GUI倍率を使います。設定画面の下部に実効倍率と加工状態を表示します。

標準Unifontは元の1画素をGUIの1/2単位で描きます。GUI4・文字倍率100%では元のドットが2画面pxなので、2画面pxを選んでも元の字形と同じ見た目になります。この条件では「元のUnifontと同じ」と表示します。加工が動いていないことを示すものではありません。ただし、報告された実機での無変化がこの条件だけによるものかは未確認です。

GUI3・2画面pxで線が太くつぶれるという実機報告があります。元のドットを含むブロックを白くする現行処理では線が広がるためです。今回は1画面pxで良好という報告を尊重し、画像加工方式の変更は行っていません。2画面pxの可読性改善は未完了です。

標準英字のドット幅と設定した画面px数が一致する場合、美咲ゴシック第2を自動選択します。

- 標準のビットマップ英字はGUI1単位が1ドットです。GUI3なら文字倍率100%で1ドット3画面pxなので、設定3で一致します。GUI2なら設定2です。
- ピクセル加工ON・GUIスケールと画面px数が同じ・Unicodeフォント強制OFFのときだけ、自動で美咲を使用します。設定画面の下部にも判定を表示します。
- これは標準ビットマップ英字を基準にした判定です。外部リソースパックの任意の英字フォントを画像解析する機能ではありません。
- 不一致の場合は標準フォントを使い、Unifont部分にドット加工を適用します。OFFでは自動選択も画像加工も停止します。文字サイズ設定は独立して利用できます。

## ぼやけへの対処

0.4.1の半透明ブロックを廃止し、完全な白／透明だけで画像を生成します。細線を消さないため、ブロックに線が含まれれば白にする方式です。ドットを粗くすると線が太くなったり隣の線とつながったりする可能性があります。

描画開始位置は実画面のピクセル境界へ揃えます。文字サイズ100%の標準的な描画で、1/2/3/4画面pxのドットを指定します。別途倍率を変更したり、他Modの描画変換が入ったりするとドットも拡大縮小するため、任意の倍率で完全な整数ドットになる保証はありません。

GUIスケール・ピクセル加工ON/OFF・画面px設定の変更時にはリソースを再読み込みします。文字幅計算と描画に同じフォント参照先を使います。美咲は元の画像・JSONを維持し、標準フォント上書きファイルassets/minecraft/font/default.jsonは同梱しません。

既存の文字倍率・画面px設定は保持します。GUI3で英字と同じドット幅にするには、倍率100%・ピクセル加工ON・3画面pxで比較してください。Unicodeフォント強制はOFFにします。

## 検証とビルド

JDK25 / Gradle9.7.1: `gradle clean build`、`python scripts/verify_font_assets.py`。

単体テストでは英字グリッド一致・不一致、OFF、Unicode強制、フォント参照先の復帰、白／透明以外の画素を生成しないこと、GUIスケールごとのドット数、描画範囲の保持を確認します。Actionsでビルドと元フォント・権利表示の保持を検証します。

Minecraft実機での見た目・切り替え動作は別途確認が必要です。
