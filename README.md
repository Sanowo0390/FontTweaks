## 0.12.1 — GUI4以上へ統合、GUI3補正スイッチ廃止、プリセット1のGUI3を1pxへ

- **GUI別プロファイルは4つ**：GUI1 / GUI2 / GUI3 / **GUI4以上**。GUI5以上という独立グループは廃止しました。GUI4、5、6…は設定ファイル内の同じ `guiScaleProfiles["4"]` を参照します。
- 「GUI3でドット数を補正」は設定画面・設定項目・内部の独立判定から削除しました。GUI3の補正は各GUIプロファイルの **Unifontを加工する** のON/OFFで直接制御します。
- **プリセット1（ドット補正のみ）**：GUI1はUnifont加工ON・1px、GUI3も**Unifont加工ON・1px**。GUI2とGUI4以上は加工OFF、標準フォントです。全GUIで英字のフォント置換はOFF。
- プリセット2：GUI1＝美咲・3px、GUI3＝PixelMplus12・2px。GUI2・GUI4以上＝標準・無加工。
- プリセット3：GUI1〜GUI4以上の全プロファイルで美咲・3px。
- **旧設定移行**：以前のGUI4とGUI5以上の設定が両方ある場合はGUI4の設定を優先し、旧GUI5以上のキーを削除します。GUI4の設定が存在せずGUI5以上だけ保存されている場合は、その設定をGUI4以上へ引き継ぎます。旧 `gui3DotCorrection` は読み込み時に無視し、次回保存時に出力しません。

GUIの文字サイズ・文字間隔・ブラックリスト・GUI別英字置換・Unifont加工設定は引き続き利用できます。Minecraft実機表示は未検証のため、ビルド・JUnit・Mixinテストとは区別してください。

| 2. 補正＋フォント変更 | 美咲・3px設定 | 標準・無加工 | PixelMplus12・2px設定 | 標準・無加工 | 標準・無加工 |
| 3. 常に美咲 | 美咲・3px設定 | 美咲・3px設定 | 美咲・3px設定 | 美咲・3px設定 | 美咲・3px設定 |

- **プリセット1**：GUI1 / GUI3でUnifontのドットを読みやすくする方針です。GUI1は1px、GUI3は2pxへ補正します。物理ドット倍率は整数ピクセルへの丸めを含むため厳密な1.5倍ではありません。
- **プリセット2**：GUI1を美咲、GUI3をPixelMplus12（PixelPlus12と呼ばれていたフォント）へ切替します。3px・2pxはそのGUIのドット設定として保存されますが、**Unifont専用のラスター処理は美咲やPixelMplusの元画像自体を加工しません**。
- **プリセット3**：GUIスケールにかかわらず日本語を美咲ゴシック第2で描画します。各GUIプロファイルのドット数は3px、英字置換はOFFです。

### カスタム編集

同じフォント・ドットタブに残したGUI1 / GUI2 / GUI3 / GUI4 / GUI5以上の詳細グループから、以下をGUIサイズごとに独立して変更できます。

1. 1ドットの画面px（自動 / 1～4）
2. 既存フォントを使用する（3pxなら美咲、その他はPixelMplus12）
3. **Unifontを加工する** ON/OFF
4. **英語文字も置き換える** ON/OFF

GUI3の「GUI3でドット数を補正」も引き続き利用可能です。**既存フォントを使用する**がONでも英字置換をOFFにすれば、ASCII英字・ラテン文字はMinecraft標準のままです。個別の値を編集するとプリセットの表示が「カスタム」になります。

プリセットを変更して保存した場合は新しいプリセット内容を優先し、GUI別の個別編集も同時に行った場合はプリセットが優先されます。プリセット適用後、必要なら再度設定画面を開き「カスタム」で編集してください。

### 既存設定との互換性

従来の設定ファイル `config/fonttweaks.json` に保存されたGUI別プロファイル・ドット数・既存フォント指定は読み込み時に保持され、プリセット選択を明示するまで勝手に置き換えません。新しい各GUIの英字置換・Unifont加工設定が存在しない場合は、旧グローバル設定を引き継ぎます。

GUIスケール変更やフォント選択のみの変更では原則としてリロード不要です。焼き込み済みUnifontのドット画像が変わる場合のみ再読み込みを要求します。

## 0.10.0 — GUI3ドット補正・英字を除外する間隔調整・設定UI整理

YACLのタブは**フォント・ドット → 文字 → 除外文字**の順に変更しました。

- **フォント・ドット**：ピクセル加工ON/OFF、1ドットの画面px（自動／1～4）、**GUI3でドット数を補正**、使用フォント（**標準／美咲／PixelMplus／自動**）、英字フォント置換。
- **文字**：文字サイズ、横方向の文字間隔、縦方向の行間、**英字を間隔調整から除外**。
- **除外文字**：以前と同じブラックリスト編集。

### フォント選択

「GUIサイズに応じて美咲に切替」の独立項目を削除し、「使用するフォント」の「自動」に統合しました。自動ではGUIスケール1～2で美咲ゴシック第2、GUIスケール3以上で通常のMinecraftフォントを使用します。フォント切替そのものではリソース再読み込みは不要です。既存の `resourcePackEnabled`・`resourcePackFont`・`guiScaleDependentFont` キーから選択状態を読み取るため、既存設定は維持します。

### GUIスケール別のドット加工

- **GUI2とGUI4、ドット数1px**：Unifontを加工しません（元の字形を使用）。
- **GUI3、ドット数2px、補正ON**：従来と同じ2px加工アルゴリズムを使用。
- **GUI3、補正OFF**：元のUnifontを使用します。
- それ以外の加工指定はGUI3基準のラスターを利用し、GUI3の補正を有効にすると指定したドット数に変換されます。
- 加工テクスチャを持つフォントはMinecraftでキャッシュされます。**ウィンドウサイズ変更が「元の字形 ↔ 加工字形」の切替を伴う場合だけ**再読み込みを要求します。変わらないGUIサイズ変更では再読み込みしません。これはGUI2/4で無加工にするための制約であり、過去の「GUIサイズ変更では常に無再読み込み」という挙動からの変更です。

### 英字を間隔調整から除外

YACL「文字」タブの「英字を間隔調整から除外」をONにすると、ラテン文字・ASCIIの文字間隔（字送り）を標準のまま維持し、日本語など非ラテン文字の字送りだけを調整します。幅計測と描画処理の双方に適用します。

縦の行間も、**英語だけの行は通常の行高**、日本語を含む行は設定した行高にする処理を、折り返し文章・Minecraftの複数行ラベル・テキストツールチップで行います。日本語と英語が混じる行は行全体に設定した行間が適用されます。Minecraftチャット欄の行高は全行共通で管理されるため、チャットの縦方向は引き続き共通行間の対象です。

### Sodium / YACLなどの画面

以前、YACLの設定画面を**すべて**文字サイズと文字間隔の加工対象外にしていた問題を修正しました。FontTweaks自身の設定画面だけを除外し、Sodiumなど外部ModがYACLで描画するテキストにも変更を反映できるようにしました。特殊なカスタム描画のModは対象外の場合があります。

ビルド・Mixin適用・字送りと行高の自動テストを実施していますが、実ゲーム内でのSodium/YACLを含むすべてのGUI表示は未検証です。

## 0.9.0 — 画面px「自動」とカテゴリ統合

YACLのタブを**5つから3つ**に整理しました。

| タブ | グループ・設定 |
| --- | --- |
| **文字** | 文字サイズ（全体、画面、HUD、ボタン、チャット）＋文字間隔と行間（文字の横間隔、全体・文章・ツールチップの行間） |
| **フォント・ドット** | Unifontピクセル加工ON/OFF、**1ドットの画面px: 自動・1・2・3・4**、GUI縮小時の美咲自動切替、内蔵フォント選択、英字置換 |
| **除外文字** | ブラックリストの追加・個別編集・削除 |

### 画面pxの「自動」について

- 設定ファイルでは `pixelBlockSize: 0` が自動、`1`〜`4` が手動です。**新規インストール・設定リセットの初期値は従来通り1px**。従来の設定ファイルに入っている1〜4はそのまま維持されます。
- **自動モードはGUIスケール3を基準とし、2画面px/ドットの加工アトラス**を選びます。自動と手動2pxは同じキャッシュを共有するため、この二者間の変更ではフォントの再読み込みは不要です。
- すでにある「GUIサイズに応じて美咲に切替」もONにすると、**GUI3以上で加工Unifont、GUI2以下では美咲ゴシック第2**へ自動的に切り替わります（通常のリソースパック置換設定がOFFの場合）。GUIの縮小・拡大だけでは再読み込みしません。英字とブラックリストの扱いも既存設定に従います。
- **注意**：アトラスはGUI3で固定生成しているため、GUI3以外で厳密な整数画面pxになるわけではありません。これをGUI変更だけで完全に実現するには複数解像度のフォントアトラスなど別方式が必要です。本バージョンは不要なリソース再読み込みを避け、GUI2で美咲フォントに切り替える方式です。

## 0.8.0 — 文字間隔（横）とGUIサイズ別フォント自動切替

- **文字間隔（横）** `letterSpacing` を追加。YACLの「文字間隔・行間」タブの先頭で編集できます。初期値は **0**、範囲は **-2.0〜4.0 GUI単位**（小数直接入力可）。プラスで文字間を広げ、マイナスで狭めます。**縦の行間は変更しません。**
- Minecraft 26.3の **`Font$PreparedTextBuilder`（実際の描画ペン位置）と`Font`の`StringSplitter`（文字幅計算・折り返し）を同時に補正**します。見た目の文字間隔だけ変えて中央揃えやチャット幅がずれる問題を避ける構成です。文字の画像や高さは変更しません。
- **ピクセル加工のデフォルトを1画面px**にしました。既存の `config/fonttweaks.json` に `pixelBlockSize: 2` 等が明記されている場合は、個人設定を尊重してそのまま保持します。新規導入または設定リセット時は1です。
- **GUIサイズに応じて美咲へ切替** `guiScaleDependentFont` を「ドット」タブに追加（デフォルトOFF）。ONにすると、**ピクセル加工がONでGUI3以上なら通常のフォント設定**、ウィンドウ縮小や他画面への切り替え等で**GUI2またはGUI1になったときだけ美咲ゴシック第2**へ自動切替します。GUI3へ戻れば元のフォントに戻ります。フォントの再読み込みは不要です。
- 例：`pixelationEnabled: true`, `pixelBlockSize: 2`, `guiScaleDependentFont: true`, `resourcePackEnabled: false` なら、GUI3では2px基準で加工した標準Unifont、GUI2では美咲ゴシック第2、GUI3へ戻ると再びUnifontになります。
- 自動切替は **明示的に選択されたカスタムフォントを上書きしません**。ブラックリストの文字も元フォントを維持し、英字置換がOFFなら半角英数字は標準フォントのままです。自動切替と内蔵フォント置換は別設定なので、通常のフォント置換がOFFでもGUI2での美咲への切替を利用できます。
- GUIスケール変更自体は以前の0.6.1と同様、リソースの再読み込みを要求しません。ピクセル加工のON/OFFやドット値の変更のみフォントアトラス再生成が必要です。

この機能は文字幅計測・Mixin適用の自動テストを含みますが、実際のMinecraftウィンドウの表示や他Modとの組み合わせはユーザー環境での検証が必要です。

- 右側の説明ペインにはYACLの `OptionDescription.customImage` を用いて、日本語・英字の**現在適用中のフォント表示例**を追加。
- YACLの編集内容は画面下部の適用操作でまとめて保存し、キャンセルすると未保存の変更は反映されません。チャットの折り返しは保存後に更新します。

なおこのプレビューはYACLが保存前の入力を適用しないため、**適用済みの設定**を表示します。入力途中の値をリアルタイムで反映するものではありません。Minecraft実機でのGUI描画・他Modとの組み合わせは未検証です。

## 0.6.1の変更：不要なリソース再読み込みの削減

- ブラックリストの**追加・削除・全削除**は、FontMixin の文字ごとのフォント判定に即時反映します。リソース再読み込みは行わず、必要なチャット折り返しのみ再計算します。
- 美咲・PixelMplusフォント選択、リソースパック適用ON/OFF、英字置換ON/OFFも、描画時のフォント選択を切り替えるだけにし、不要なリソース再読み込みを停止しました。
- **GUIスケール変更時**はリソース再読み込みを行いません。Unifontの加工アトラスは起動時のGUIスケールに関係なく**GUI3基準の固定解像度**で生成します。これによりGUI3へ戻しても基準のピクセル表示を維持できます。
- 例外として**ピクセル加工自体のON/OFF・1〜4pxの切り替え**は、既にキャッシュ済みの字形画像を変えるため、引き続き再読み込みが必要です。
- GUI3以外では固定アトラスが画面に拡大・縮小されるため、指定した「1ドット＝N画面px」と厳密に一致しない場合があります。厳密なドット数を求める場合はGUI3を使ってください。

## 0.6.0の変更

- 数値項目の右側に「戻す」を追加しました。その項目だけを初期値100%に戻します。ピクセル加工ON/OFF、画面px数、リソースパック適用、フォント選択、英字ON/OFFにも個別の戻すボタンがあります。全体の初期化も残しています。
- 数値入力を変更した後、24bit色をARGB色として使っていた問題を修正しました。正常入力は不透明の白、不正な値は不透明の赤です。
- ブラックリストを追加・個別削除できる一覧にしました。複数文字を追加した場合もUnicodeの1コードポイントごとの行に分け、重複は登録しません。ページ送りに対応します。旧blacklistedCharactersの文字列は個々のblacklistedEntriesへ移行して保存します。
- ブラックリストはフォント置換だけの除外になりました。登録文字でもUnifontのピクセル加工は、加工ONなら適用します。加工の除外に使っていた古い焼き込みコンテキストは削除しました。
- プレビューに「文字サイズ」「行間」の切り替えを追加しました。行間は手計算したサンプルではなく、実際のMultiLineLabel、textWithWordWrap、ClientTextTooltipの経路で2行を描画します。行間の項目を編集してからプレビューを開くと行間の画面を表示します。

## 行間について

「行間全体」は標準の複数行ラベル、折り返し文章、ツールチップ、チャットの共通倍率です。「文章の行間」「説明文の行間」は共通倍率に乗算します。単一行のメニューボタン同士の距離や、他Modが固定座標で並べる一覧項目を移動する設定ではありません。

今回、隔離したFabric/MinecraftをpreLaunchまで起動し、対象クラスへのMixin適用と、実メソッドの行送り変化を確認するテストを追加しました。100%→200%で標準ラベルの行送り9→18、ツールチップ高さ10→20となることを検証します。設定ファイルの保存と再読み込みも通します。通常のゲーム画面や他Modを含めた表示はこのテストに含まれません。「全て変わらない」という実機報告の原因を確定したものではありません。

## フォント・除外文字

Mod Menu → FontTweaks → 「フォント・除外文字」で操作します。

リソースパック適用OFFでは、美咲・PixelMplusのどちらも適用しません。ONならPixelMplus12 Regular、美咲ゴシック第2、自動から選べます。自動は標準英字とドット幅が一致すれば美咲、それ以外はPixelMplusを使います。英字置換OFFなら半角英数字・記号とラテン文字は元のフォントです。

ブラックリストは「追加」で登録し、各行の「削除」で1文字ずつ削除します。登録した文字は非表示にはせず、元のフォントへ戻します。Unifontで描く文字には加工ONならピクセル加工が適用されます。Bitmap/TTFフォントはUnifont加工の対象外です。明示的なカスタムフォントは保持します。

フォント選択・ブラックリスト・英字置換などは再読み込みなしで即時反映します。ピクセル加工のON/OFF・画面px数変更だけは、キャッシュ済みのUnifont字形を再生成するため再読み込みが必要です。数値の倍率・行間設定も再読み込みなしで参照します。

## ピクセル加工とサイズ

1ドットは1〜4画面px、文字倍率100%時の基準です。サイズ変更とは独立しています。倍率を変更するとドットも拡大縮小します。Unifontの元の画素を1ブロックへ割り当て、細い空白を安全に戻せる箇所では隙間保護を行います。すべての隙間を保持できる保証はありません。GUI3・1画面pxは良好と報告された方式を維持しています。

加工アトラスはGUI3を基準として固定生成します。GUI4など別のGUIスケールでは表示ピクセル数が変わる可能性がありますが、GUIスケールの切り替えによるリソース再読み込みは発生しません。PixelMplus・美咲の字形は既製フォントのため、Unifont用の画面px加工設定では変更しません。文字サイズ・行間は別途調整できます。

## Build / 検証

JDK25 / Gradle9.7.1:

- `gradle clean build`
- `gradle runSmoke -x downloadAssets` — 隔離起動テスト。ゲーム画面を開く前に終了します。
- `python scripts/verify_font_assets.py`

Actionsでも単体テスト、隔離起動テスト、配布JAR検証を行います。smoke用のMod JARはbuild/smokeに生成し、通常配布JARには同梱しません。

PixelMplus12 Regularは公式固定コミットd89b95f04eeb95bf98bb09cb9234a2f99d186df5からビルド時に取得します。SHA-256は02f19467ea7cc235cc06c570b7f6c3b0a12a6f682bc8d74c43f2d323d97bcd12です。元の美咲の画像・JSON・権利表示も維持します。assets/minecraft/font/default.jsonは同梱しません。
