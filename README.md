# FontTweaks 0.5.2

Minecraft 26.3 / Fabric / client-only

## フォントと除外文字

Mod Menu → FontTweaks → 「フォント・除外文字」を開きます。

- **リソースパック適用：ON/OFF** — 美咲・PixelMplusの両方をまとめた適用スイッチです。OFFではどちらも適用せず、元のフォントを使います。初期値はOFFです。
- **フォント** — ONの場合、PixelMplus12 Regular（初期値）、美咲ゴシック第2、自動を選択できます。自動は標準英字とドット幅が一致すれば美咲、それ以外はPixelMplus12を使います。美咲もリソースパック扱いなので、OFF時に自動適用することはありません。
- **英字フォントを置き換える：ON/OFF** — フォント置換に半角英数字・記号とラテン文字を含めるか選びます。OFFが初期値で、その文字は元のフォントを使います。日本語の適用には影響しません。
- **除外する文字（ブラックリスト）** — 例として「！？★」を入力すると、その3文字はフォント置換とUnifontのピクセル加工から除外します。文字は消さず、元のフォントで表示します。区切り記号や正規表現ではなく、入力された各文字が対象です。空欄なら除外なしです。補助文字・絵文字もコードポイント単位で扱います。
- ON/OFFボタンの操作直後にリソース再読み込みを要求します。ブラックリストは入力停止から350ms後に要求します。読み込み中の追加変更は完了後にもう一度反映し、途中の変更を取りこぼさない構成です。「完了」またはEscで戻る場合は入力待ちを打ち切ります。設定はconfig/fonttweaks.jsonへ保存します。
- 初期化は「フォント・除外文字」ページに移しました。文字倍率・行間・加工・フォントと除外文字をすべて初期値へ戻します。

リソースパック適用OFFなら、フォント選択・ドット幅に関係なく元のフォントを使います。ONでは、明示的なカスタムフォントと除外文字の保持 → 英字OFFの保持 → 選択したフォントの順に適用します。PixelMplus未収録の文字は標準フォントへフォールバックします。英字OFFはフォントの置換範囲を指定する項目で、Unifont加工からも外したい文字はブラックリストへ登録します。

## 0.5.2：美咲も適用スイッチで制御

0.5.1まではOFF時も美咲へ自動切り替えする分岐が残っていました。美咲も内蔵リソースパックとして同じ適用スイッチに従うよう修正しました。ピクセル加工は独立したUnifont加工機能のため、フォントの置換をOFFにしても加工ONなら有効です。元の字形を加工なしで表示したい場合は両方OFFにします。

## 再読み込み・行間・サイズ確認

「行間全体」を追加しました。折り返し文章、標準MultiLineLabel、ツールチップの文字行、チャットに共通倍率を適用します。文章の行間・説明文の行間は共通倍率と乗算します。チャットのバニラ行間も保持して共通倍率を掛け、描画側とページ数・クリック位置側に同じ値を使います。標準MultiLineTextWidgetの高さと折り返し文章の高さ計算も調整します。

独自Modが固定座標で並べる文字、一覧の項目間隔、画像ツールチップ、任意の独自描画までは全体行間の対象ではありません。文字サイズと行間は別の設定です。

設定画面のサンプルは、最後に編集した画面・HUD・ボタン・チャットの倍率を反映します。別の「プレビュー」画面でそれぞれの倍率と2行サンプルを比較できます。設定操作部自体は読みやすい固定倍率です。サンプルは選択中の実フォントを使います。PixelMplus適用ON、加工OFFでも各倍率の計算は有効です。

0.5.0のサイズ変更処理にPixelMplus適用時だけ無効化する条件は見つかっていません。既存サンプルが画面用倍率だけを表示していた問題を改善しています。実機で報告されたサイズ無変化の原因を確定したものではなく、実表示の確認が必要です。

再読み込みはゲームの次のクライアントtickで開始します。同時の複数要求はまとめ、読み込み開始後に来た要求は完了後に処理します。成功後にチャットの折り返しを更新します。失敗はログへ記録し、無限に自動再試行しません。

## PixelMplus12 Regular

作者の公式TTFを改変せず同梱します。固定コミットd89b95f04eeb95bf98bb09cb9234a2f99d186df5からビルド時だけ取得し、SHA-256を検証します。起動時のダウンロードはありません。

SHA-256: `02f19467ea7cc235cc06c570b7f6c3b0a12a6f682bc8d74c43f2d323d97bcd12`

独立したfonttweaks:pixelmplus12の名前で読み込み、文字の描画と幅計算の両方で選択します。標準フォントを無条件に上書きするassets/minecraft/font/default.jsonは同梱しません。

TTFの設定はsize 8、oversample 3です。アウトラインの実機での見え方、ベースライン、混在時の行間・文字幅は未検証です。PixelMplus使用中のドット感はPixelMplusの字形とレンダリングによるもので、Unifont用の画面px加工設定では変化しません。フォントを切り替えるため、字幅・折り返しが変わる場合があります。

## ピクセル加工

加工ON/OFFと文字サイズ・行間は独立しています。1ドットは1〜4画面pxから選びます。表示px数は文字倍率100%時の基準です。倍率を変更するとドットも拡大縮小します。

リソースパック適用ONかつフォント選択が自動の場合に限り、標準ビットマップ英字とドット幅が一致すれば美咲を使います。GUI3なら3画面px、GUI4なら4画面pxです（加工ON・Unicodeフォント強制OFF）。外部フォント画像を解析する判定ではありません。英字OFF・ブラックリストはこの美咲選択にも適用します。

不一致ならUnifontを加工します。元の画素の中心を1つの出力ブロックに割り当て、元の細い空白を戻せる箇所では隙間保護を行います。すべての隙間を維持できる保証はありません。GUI3・1画面pxの加工方式は0.4.4と同じです。GUI4・2画面pxは元のUnifontと同じドット幅です。

## Build / 検証

JDK25 / Gradle9.7.1: `gradle clean build`、`python scripts/verify_font_assets.py`。

単体テストでフォント選択、英字の範囲、ブラックリスト優先、補助文字、設定の往復、除外文字のアトラス描画時の加工抑止、既存の隙間保護を確認します。Actionsでは元の美咲データ、PixelMplusの正確なハッシュ、権利表示を配布JARから検証します。

Minecraft実機での混在表示、設定画面の配置、Mixin適用とリロード後の挙動は別途確認が必要です。
